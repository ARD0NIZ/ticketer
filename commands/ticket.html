/ticket

Create a new support ticket

Description

The /ticket command allows users to create a new support ticket in your Discord server. When executed, the bot will create a private channel where the user can describe their issue and receive help from your support team.

/ticket [reason]

Parameters

  • reason (optional): Brief description of why you're creating the ticket

How it works

  • A new private channel is created in the configured ticket category
  • Only the ticket creator and support staff can see the channel
  • The bot sends an initial message with ticket information
  • Support team members are automatically notified
