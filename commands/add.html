/add

Add a user to the current ticket

Description

The /add command allows support staff to add additional users to a ticket channel. This is useful when multiple people need to be involved in resolving an issue.

/add <user>

Parameters

  • user (required): The Discord user to add to the ticket

How it works

  • Grants the specified user view and send message permissions
  • The user can now see all messages in the ticket
  • The user can participate in the conversation
  • All participants are notified when someone is added

Permissions Required

  • Must be used in a ticket channel
  • Must have support role or administrator permissions
