/ticketcat

Set up ticket channel category

Description

The /ticketcat command sets the category where all new ticket channels will be created. This is a required setup step before users can create tickets.

/ticketcat

How it works

  • Sets the ticket channel category for your server
  • All new tickets will be created in the #Tickets category
  • After setup, you can use /ticketpanel in channels where users should open tickets
  • Staff members must have the Manage Channels permission to be recognized as staff

Permissions Required

  • Administrator permissions required
  • Bot needs permission to create channels in the category
Ticketer
Ticket Channel Category
The tickets will be created in the category #Tickets.

You can now use /ticketpanel in the channel where users should be able to open a ticket.

Staff members must have the Manage Channels permission in their roles or profiles in order to be recognized as staff.
