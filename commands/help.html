/help

Display all available commands

Description

The /help command displays a comprehensive list of all available Ticketer commands along with brief descriptions and usage information. This is perfect for new users getting started or as a quick reference.

/help [command]

Parameters

  • command (optional): Get detailed help for a specific command

How it works

  • Shows all available commands in an organized embed
  • Commands are grouped by category (tickets, management, configuration)
  • Each command includes a short description
  • Links to full documentation for detailed information

Example Usage

  • /help - Show all commands
  • /help ticket - Get detailed info about the ticket command
