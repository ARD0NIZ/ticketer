/help

Display all available commands

Description

The /help command displays information about Ticketer, including links to the official website, owner portfolio, and a list of all available commands for managing your ticket system.

/help

How it works

  • Displays the Ticketer website link for full documentation
  • Shows all available bot commands in a clickable format
  • Provides link to the owner's portfolio
  • Includes latest patch notes to keep you informed of updates

Available Commands Shown

  • /help - Display this help message
  • /ticketcat - Set up ticket channel category
  • /ticketpanel - Create ticket submission panel
  • /ticketcontrolpanel - Access ticket management controls
  • /statistics - View bot statistics
  • /config - View current bot configuration
