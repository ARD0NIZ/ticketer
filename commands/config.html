/config

Configure bot settings for your server

Description

The /config command allows server administrators to configure Ticketer's settings. Set up ticket categories, transcript channels, support roles, and customize how the bot operates in your server.

/config [option] [value]

Configuration Options

  • ticket_category: Set the category where new tickets will be created
  • transcript_channel: Set the channel where transcripts will be sent
  • support_role: Set the role that can manage tickets
  • ticket_prefix: Customize the ticket channel name prefix
  • view_settings: Display current configuration

How it works

  • Interactive menu shows all available configuration options
  • Changes take effect immediately
  • Configuration is saved per-server
  • All settings can be modified at any time

Permissions Required

  • Administrator permissions required
  • Bot needs permission to manage channels and roles
