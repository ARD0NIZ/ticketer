/statistics

Display bot statistics and ticket metrics

Description

The /statistics command displays comprehensive statistics about the bot including server count, user count, performance metrics, and detailed ticket statistics.

/statistics

Statistics Sections

  • About: Guild count, user count, ping, command count, and uptime
  • Live Stats - Tickets: Total tickets created, claimed, deleted, and pending
  • Functions Used - Tickets: Transcript, reopen, and close counts

How it works

  • Displays real-time bot statistics and metrics
  • Shows ticket system usage and performance data
  • Includes bot latency and uptime information
  • Provides insights into ticket workflow and management

Permissions Required

  • Can be used by anyone in the server
  • No special permissions required
