/ticketpanel

Create a ticket submission panel

Description

The /ticketpanel command creates an interactive panel with a button that allows users to create support tickets. This panel provides a user-friendly interface where members can simply click a button to submit a support ticket.

/ticketpanel

How it works

  • Creates an embed message with a "Create a Ticket" button
  • Users can click the button to create a new support ticket
  • The panel explains that the support team will respond promptly
  • Panel can be placed in any channel where users should be able to open tickets

When to use

  • Place in your support or help channel
  • Provides an easy, visible way for users to get help
  • Must configure ticket category first using /ticketcat

Permissions Required

  • Must have Manage Channels permission or be an administrator
  • Bot needs permission to send messages and create embeds in the channel
