Bot Commands

Complete reference for all Ticketer commands. Click on a command to see detailed information and examples.

/help

Get Help

Display a list of all available commands with brief descriptions and usage information.

 /ticketcat

Setup Ticket Category

Configure the category where new ticket channels will be created in your server.

 /ticketpanel

Create Ticket Panel

Set up an interactive panel with a button that allows users to create support tickets easily.

 /ticketcontrolpanel

Ticket Control Panel

Create a control panel with management buttons to claim, close, delete, or generate transcripts for tickets.

 /statistics

Bot Statistics

View comprehensive bot statistics including server count, ticket metrics, and performance data.

 /config

Configure Bot Settings

Set up and customize Ticketer for your server: ticket categories, transcript channels, support roles, and more.
